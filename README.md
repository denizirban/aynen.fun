# AYNEN.

Gereksiz derecede gerekli oyunlar.

A mobile-friendly, no-build micro-game website with a transparent cat mascot and six playable games.

## Run locally

Open `index.html` in a browser, or serve the directory with `python3 -m http.server 3000`.

## Deploy

Connect the GitHub repository `denizirban/aynen.fun` to your Vercel project under **Settings → Git**, and set `main` as the production branch. Use **Other** framework, with no build command and the repository root as the output directory.

## Contents

- `index.html` — responsive landing page and all six playable mini-games.
- `cat.webp` — optimized transparent cat mascot image.

Games: Hiçbir Şey Yapma, Hayır Diyebilir misin?, Bir Evrak Eksik, Bir Şey Soracağım, Az Kaldı, Başarı Simülatörü.
